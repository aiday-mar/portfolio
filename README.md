# Aiday Marlen Kyzy — Portfolio

**Live site:** [portfolio-aidays-projects.vercel.app](https://portfolio-aidays-projects.vercel.app)

Personal portfolio website built with [Next.js](https://nextjs.org), React, TypeScript, and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
